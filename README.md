
Smart Farm – Crop Advisory System

Project Overview

Smart Farm is a bilingual (English and Luganda) web-based crop advisory system designed to help smallholder farmers in Masaka District, Uganda, get practical guidance on crop problems and fertilizer recommendations.

Objectives

* Help farmers identify common crop-related problems.
* Provide practical fertilizer and crop management recommendations.
* Make agricultural guidance accessible in both English and Luganda.

Features

* English and Luganda language support.
* Crop problem advisory.
* Fertilizer recommendations.
* Simple and user-friendly interface.

Technologies Used

* HTML
* CSS
* JavaScript

How to Use

1. Open the website.
2. Select your crop.
3. Select or describe the crop problem.
4. View the recommended advisory.
